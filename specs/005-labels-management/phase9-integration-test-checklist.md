# Phase 9 統合テスト チェックリスト

## T032: E2Eテスト

### ラベルフィルターのテスト

#### 準備
- [ ] テスト用のユーザーでログイン
- [ ] テスト用のタグを3つ作成（例: "urgent", "work", "personal"）
- [ ] テスト用のTODOを複数作成
  - [ ] TODO 1: tags = ["urgent", "work"]
  - [ ] TODO 2: tags = ["urgent", "personal"]
  - [ ] TODO 3: tags = ["work", "personal"]
  - [ ] TODO 4: tags = ["urgent", "work", "personal"]
  - [ ] TODO 5: tags = []（タグなし）

#### ラベル作成テスト
- [ ] ラベル一覧ページに移動（/labels）
- [ ] "Create Label" ボタンをクリック
- [ ] ラベル作成モーダルが開く
- [ ] ラベル名を入力（例: "Urgent Work"）
- [ ] 説明を入力（例: "High priority work tasks"）
- [ ] タグを選択（"urgent" と "work"）
- [ ] 推定TODO数が表示される（2つのTODOが表示されるはず: TODO 1, TODO 4）
- [ ] "Create" ボタンをクリック
- [ ] ラベルが作成され、一覧に表示される
- [ ] 作成されたラベルのTODO数が正しい（2）

#### ラベル編集テスト
- [ ] 作成したラベルの "Edit" ボタンをクリック
- [ ] ラベル編集モーダルが開く
- [ ] 現在の情報が表示される
- [ ] タグを変更（"personal" を追加）
- [ ] タグ変更確認ダイアログが表示される
- [ ] 変更前後のタグが表示される
- [ ] 変更前後のTODO数が表示される（Before: 2, After: 1 - TODO 4のみ）
- [ ] "Update" ボタンをクリック
- [ ] ラベルが更新される
- [ ] TODO数が更新される（1）

#### ラベルによるTODOフィルタリングテスト
- [ ] TODOページに移動（/todos）
- [ ] "Filter by Label" ドロップダウンが表示される
- [ ] ドロップダウンに作成したラベルが表示される
- [ ] ラベルを選択（"Urgent Work"）
- [ ] フィルタリングされたTODOが表示される（AND条件: urgent AND work AND personal）
- [ ] 正しいTODOが表示される（TODO 4のみ）
- [ ] URL に "?label=:ulid" パラメータが追加される
- [ ] ページをリロードしても同じフィルター状態が維持される

#### ラベルとタグの併用テスト
- [ ] タグフィルターで "urgent" を選択
- [ ] ラベルフィルターで "Urgent Work" を選択
- [ ] 両方のフィルターが適用される
- [ ] URL に "?tags=:ulid&label=:ulid" パラメータが追加される

#### ラベル削除テスト
- [ ] ラベル一覧ページに移動
- [ ] 作成したラベルの "Delete" ボタンをクリック
- [ ] 削除確認ダイアログが表示される
- [ ] 影響を受けるTODO数が表示される
- [ ] "Delete" ボタンをクリック
- [ ] ラベルが削除される
- [ ] TODOページでラベルフィルターからラベルが消える
