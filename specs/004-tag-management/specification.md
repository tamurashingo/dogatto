# 004-tag-management 仕様書

## 概要

dogatto（タグベースTODO管理アプリケーション）のタグ管理機能を実装します。
ユーザーがカスタムタグを使用してTODOを整理・分類し、関連タスクの検索と管理を容易にします。

## 目標

ユーザーが以下の操作を実行できるようにする：
- カスタムタグの作成と管理
- TODOへの複数タグの割り当て
- タグによるTODOのフィルタリング
- タグの統計情報の表示
- タグを使用した効率的なTODO整理

## 前提条件

- Phase 1（初期セットアップ）完了
- Phase 2（認証システム）完了
- Phase 3（TODO基本機能）完了
- ユーザーは認証済みであること
- ユーザーはタグ付け可能なTODOを持っていること

## スコープ

### Phase 4に含まれる機能

✅ **タグCRUD操作**：
- タグの作成
- タグの読み取り（一覧・詳細）

- 名前（必須、ユーザーごとに一意）

- 単一タグでTODOを絞り込み
- 複数タグでTODOを絞り込み（OR条件）

✅ **タグ管理UI**：

## データモデル

### Tagテーブル

```sql
CREATE TABLE tags (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  ulid VARCHAR(26) NOT NULL UNIQUE,
  owner_id BIGINT NOT NULL,
  name VARCHAR(50) NOT NULL,
  color VARCHAR(7) DEFAULT '#3B82F6',
  created_at BIGINT NOT NULL,
  updated_at BIGINT NOT NULL,
  FOREIGN KEY (owner_id) REFERENCES users(id) ON DELETE CASCADE,
  UNIQUE KEY unique_user_tag (owner_id, name)
);
```

**カラム説明**：
- `id`: 内部ID（自動採番）
- `ulid`: 外部公開用の一意識別子
- `owner_id`: タグの所有者（ユーザーID）
- `name`: タグ名（50文字以内、ユーザーごとに一意）
- `color`: タグの色（16進数カラーコード、デフォルト青）
- `created_at`: 作成日時（Universal Time）
- `updated_at`: 更新日時（Universal Time）

### TODO_Tags 中間テーブル

```sql
CREATE TABLE todo_tags (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  todo_id BIGINT NOT NULL,
  tag_id BIGINT NOT NULL,
  created_at BIGINT NOT NULL,
  FOREIGN KEY (todo_id) REFERENCES todos(id) ON DELETE CASCADE,
  FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE,
  UNIQUE KEY unique_todo_tag (todo_id, tag_id)
);
```

**カラム説明**：
- `id`: 内部ID（自動採番）
- `todo_id`: TODO ID
- `tag_id`: タグID
- `created_at`: 関連付け日時（Universal Time）

**制約**：
- TODO削除時に関連するtodo_tagsも削除（CASCADE）
- タグ削除時に関連するtodo_tagsも削除（CASCADE）
- 同じTODO-タグの組み合わせは1つのみ（UNIQUE制約）

## APIエンドポイント

### タグ管理

#### タグ一覧取得
```
GET /api/v1/tags

Response: 200 OK
{
  "status": "success",
  "data": {
    "tags": [
      {
        "id": 1,
        "ulid": "01HQWE...",
        "name": "仕事",
        "color": "#3B82F6",
        "todoCount": 5,
        "completedCount": 2,
        "activeCount": 3,
        "createdAt": 1234567890,
        "updatedAt": 1234567890
      }
    ]
  }
}
```

#### タグ作成
```
POST /api/v1/tags

Body: {
  "name": "仕事",
  "color": "#3B82F6"  // 任意
}

Response: 201 Created
{
  "status": "success",
  "data": {
    "tag": { ... }
  }
}
```

**エラーレスポンス**：
- 400: バリデーションエラー（名前が空、不正な色コードなど）
- 409: 重複エラー（同名のタグが既に存在）

#### タグ詳細取得
```
GET /api/v1/tags/:ulid

Response: 200 OK
{
  "status": "success",
  "data": {
    "tag": { ... },
    "todos": [ ... ]  // このタグが付いたTODO一覧
  }
}
```

**エラーレスポンス**：
- 404: タグが存在しない
- 403: 他ユーザーのタグへのアクセス

#### タグ更新
```
PUT /api/v1/tags/:ulid

Body: {
  "name": "プライベート",    // 任意
  "color": "#10B981"         // 任意
}

Response: 200 OK
{
  "status": "success",
  "data": {
    "tag": { ... }
  }
}
```

**エラーレスポンス**：
- 400: バリデーションエラー
- 404: タグが存在しない
- 409: 名前の重複

#### タグ削除
```
DELETE /api/v1/tags/:ulid

Response: 204 No Content
```

**動作**：
- タグを削除すると、関連するtodo_tagsも自動削除される（CASCADE）
- TODOは削除されない

**エラーレスポンス**：
- 404: タグが存在しない
- 403: 他ユーザーのタグの削除試行

### TODO-タグの関連付け

#### TODOへのタグ割り当て
```
PUT /api/v1/todos/:ulid/tags

Body: {
  "tagUlids": ["01HQWE...", "01HQWF..."]
}

Response: 200 OK
{
  "status": "success",
  "data": {
    "todo": {
      "id": 1,
      "ulid": "01HQWE...",
      "title": "タスク名",
      "tags": [
        { "ulid": "01HQWE...", "name": "仕事", "color": "#3B82F6" },
        { "ulid": "01HQWF...", "name": "重要", "color": "#EF4444" }
      ],
      ...
    }
  }
}
```

**動作**：
- 既存のタグをすべて削除し、新しいタグセットで置き換える
- 空配列を送信するとすべてのタグが削除される
- 最大10個のタグを割り当て可能

**エラーレスポンス**：
- 400: 無効なタグULID、最大数超過
- 404: TODOまたはタグが存在しない
- 403: 他ユーザーのTODOまたはタグ

#### TODOからタグを削除
```
DELETE /api/v1/todos/:ulid/tags/:tagUlid

Response: 204 No Content
```

**動作**：
- 指定されたタグをTODOから削除
- タグ自体は削除されない

### TODOフィルタリング

#### タグでTODOを絞り込み
```
GET /api/v1/todos?tags=01HQWE...,01HQWF...

Response: 200 OK
{
  "status": "success",
  "data": {
    "todos": [ ... ]  // いずれかのタグを持つTODO（OR条件）
  }
}
```

#### タグなしTODOを取得
```
GET /api/v1/todos?untagged=true

Response: 200 OK
{
  "status": "success",
  "data": {
    "todos": [ ... ]  // タグが割り当てられていないTODO
  }
}
```

#### 複合フィルタリング
```
GET /api/v1/todos?tags=01HQWE...&status=active

Response: 200 OK
// 指定タグを持ち、かつステータスがactiveのTODO
```

## UI/UX要件

### タグ一覧ページ (`/tags`)

**コンポーネント**：
- ページヘッダーと「タグを作成」ボタン
- タグカードのグリッド/リスト表示：
  - タグ名と色インジケーター
  - TODO数の表示
  - 編集・削除ボタン
- タグが存在しない場合の空状態

**アクション**：
- 「タグを作成」クリック → タグ作成モーダルを開く
- タグカードクリック → タグ詳細ページへ遷移
- 編集ボタンクリック → タグ編集モーダルを開く
- 削除ボタンクリック → 確認ダイアログ表示

### タグ詳細ページ (`/tags/:ulid`)

**コンポーネント**：
- タグ情報（名前、色、統計）
- このタグが付いたTODO一覧
- 編集・削除ボタン

**アクション**：
- TODOクリック → TODO詳細ページへ遷移
- 編集ボタンクリック → タグ編集モーダルを開く
- 削除ボタンクリック → 確認ダイアログ、削除後タグ一覧へリダイレクト

### タグ作成/編集モーダル

**フォームフィールド**：
- 名前（テキスト入力、必須、最大50文字）
- 色（カラーピッカー、任意）

**バリデーション**：
- 名前が空の場合エラー表示
- 名前が50文字を超える場合エラー表示
- 重複する名前の場合エラー表示
- 不正な色コードの場合エラー表示

**アクション**：
- 送信 → タグ作成/更新、モーダルを閉じる
- キャンセル → 保存せずにモーダルを閉じる

### TODOフォームへの統合

**TODO作成/編集ページの拡張**：
- タグセレクターコンポーネント（マルチセレクト）
- 選択済みタグを削除ボタン付きで表示
- 「タグを追加」ボタンで追加のタグを選択

**タグセレクター仕様**：
- ドロップダウンでタグ一覧を表示
- タグ名で検索可能
- 各タグを色インジケーター付きで表示
- 最大10個まで選択可能
- 既に選択済みのタグは選択不可

### TODO一覧/詳細への統合

**TODOカード**：
- タグを色付きバッジとして表示
- タグクリック → そのタグでTODOをフィルタリング

**TODO詳細ページ**：
- すべてのタグを表示
- インラインでタグの追加/削除が可能

### タグフィルターコンポーネント

**TODO一覧ページに配置**：
- タグフィルタードロップダウン/サイドバー
- 複数タグの選択（OR条件）
- 「タグなし」オプション
- アクティブなフィルターの表示
- フィルタークリアボタン

**表示仕様**：
- 選択されたタグを色付きバッジで表示
- 各タグの右に「×」ボタン（削除用）
- タグごとのTODO数を表示

## バリデーションルール

### タグ名
- 必須
- 1〜50文字
- ユーザーごとに一意
- 前後の空白を削除
- 大文字小文字を区別しない一意性

### タグ色
- 任意（デフォルト: #3B82F6）
- 有効な16進数カラーコード形式（#RRGGBB）
- #を含めて7文字

### タグ割り当て
- ユーザーは自分のタグのみを自分のTODOに割り当て可能
- 1つのTODOに最大10個のタグ（設定可能）

## セキュリティ要件

### 認可
- ユーザーは自分のタグのみをCRUD可能
- ユーザーは自分のタグのみを自分のTODOに割り当て可能
- 他ユーザーのタグへのアクセス試行は403 Forbiddenを返す

### 入力検証
- タグ名のサニタイズ（XSS防止）
- 色コード形式の検証
- 割り当て前のタグ存在確認
- タグ割り当て前のTODO所有権確認

- 大量のタグコレクションの遅延読み込み
